스킨 이미지 (전부 선택 사항 — 없으면 게임이 알아서 그립니다)

파일을 여기에 넣고 게임에서 F7 을 누르면 즉시 반영됩니다.
확장자는 png / jpg / webp / bmp 모두 됩니다.

  track.png          트랙 바닥 (사다리꼴로 늘어납니다)
  note_pulse.png     PULSE 노트 (4버튼)
  charge_pulse.png   CHARGE(긴 노트) 몸통
  judge_line.png     판정선
  particle.png       히트 파티클 + 파편 모양. 없으면 둥근 발광/네모 조각으로 그립니다.
  hit.wav / hit.ogg   노트를 SYNC/DRIFT 로 쳤을 때 나는 소리. 없으면 공통 사운드를 씁니다.
  miss.wav / miss.ogg BREAK(놓침) 소리. 없으면 공통 사운드를 씁니다.

다른 스킨을 만들려면 assets/skins/<이름>/ 폴더를 만들고
설정 화면의 "노트 스킨"에서 그 이름을 고르면 됩니다.

스킨은 티어를 올리면서 순서대로 풀리고(COMMON → UNCOMMON → RARE → LEGENDARY),
특정 채보를 클리어해야만 풀리는 "신화(MYTHIC)" 등급 스킨도 있습니다 — fire /
space / storm 폴더 참고. 스킨마다 전용 설정이 있으면 설정 화면 "노트 스킨"
항목 바로 아래에 하위 설정으로 나타납니다.
