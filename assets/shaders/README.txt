셰이더 (GLSL)

여기 있는 파일을 고치고 게임 안에서 F6 을 누르면 재시작 없이 바로 반영됩니다.
문법 오류가 있으면 콘솔에 오류가 찍히고 이전 셰이더가 그대로 유지됩니다
(게임이 멎지 않습니다).

  quad.vert / quad.frag    게임의 모든 2D 그리기(스프라이트/노트/텍스트/파티클)가
                           지나가는 셰이더.
  fullscreen.vert          화면 전체 후처리 패스들이 공통으로 쓰는 정점 셰이더.
  bright.frag / blur.frag  블룸(밝은 부분 발광) 1~2단계.
  composite.frag           최종 합성 — 블룸 + 색수차 + 비네팅 + 화면 흔들림 +
                           플래시 + 필름 그레인 + 화면 회전을 여기서 합칩니다.
  present.frag             단순 출력(디버그/보조용).
  fxaa.frag                안티에일리어싱(FXAA).
  glitch.frag              타이틀 화면 로고 글자 전용 글리치 효과.
  flux_orb.frag            FLUX(노브) 커서 전용 — 회전하는 육각 에너지 결정처럼 보이게 합니다.
