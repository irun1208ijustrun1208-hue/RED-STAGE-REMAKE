# RED REMAKE

낙하형 리듬게임. **PULSE 4버튼 + FLUX(마우스 노브) + CHARGE(긴 노트)** 구조입니다.

## 실행 방법

1. [Releases](../../releases) 에서 최신 zip을 받습니다.
2. 통째로 압축을 풉니다(`RedRemake.exe` 파일만 따로 옮기면 안 됩니다 — 같은
   폴더의 `assets`/`songs`를 못 찾습니다).
3. `RedRemake.exe` 실행.

처음 실행하면 튜토리얼 곡과 데모 곡만 들어있습니다. 곡 선택 화면에서 `F9`
를 누르면 온라인 곡 목록에서 더 많은 곡을 바로 받을 수 있습니다.

타이틀 화면에 들어가면 자동으로 새 버전이 있는지 조용히 확인합니다 —
있으면 화면에 알려주고, `U` 를 누르면 릴리즈 페이지가 열립니다.

---

## 1. 용어

이 게임은 "회로 / 전류" 컨셉의 자체 명칭을 씁니다.

| 이름 | 뜻 | 기본 키 |
|---|---|---|
| **PULSE** | 4버튼 | `D` `F` `J` `K` |
| **FLUX** | 마우스 X축으로 조작하는 노브(단일 트랙) | 마우스 이동 |
| **CHARGE** | 길게 누르는 노트 | — |
| **CHAIN** | 연속 성공 수 | — |
| **CURRENT** | 클리어 게이지 (70% 이상 클리어) | — |

FLUX 는 "진짜 어려운 곡"의 잠금 난이도에만 쓰입니다.

**판정**

| 등급 | 뜻 |
|---|---|
| **SYNC** | 완벽하게 맞음 (기본 ±42ms) |
| **DRIFT** | 살짝 어긋남 (기본 ±100ms) |
| **BREAK** | 놓침 / 회로 끊김 |
| **LEAK** | CHARGE 를 놓아서 전류가 새는 중 |

**난이도**

`TRACE` → `SURGE` → `OVERLOAD` → `MELTDOWN` → `SINGULARITY`
(곡마다 전용 난이도 이름을 쓰기도 합니다)

## 2. 조작

### 플레이

| 키 | 동작 |
|---|---|
| `D` `F` `J` `K` | PULSE-A ~ PULSE-D (설정에서 자유롭게 리바인드 가능) |
| 마우스 이동 | FLUX(노브) — 화면 좌우로 커서를 옮겨서 목표를 따라감 |
| `ESC` | 일시정지 |
| `F5` | 처음부터 다시 |
| `F1` | 이 채보를 에디터로 열기 |
| `F8` | 오토플레이 순환 (OFF → 100% → 95% → 90% → 80%) |
| `1` `2` | 하이스피드 -/+ |
| `-` `=` | 판정 오프셋 -/+ 1ms |

배속 방식(MMOD/BPM 비례 · CMOD/고정 속도)과 노트 배치(OFF/MIRROR/RANDOM)는
설정 화면에서 고릅니다. 판정 오프셋을 손으로 맞추기 번거로우면 설정 화면의
"자동 오프셋 보정"에서 메트로놈에 맞춰 SPACE 를 몇 번 누르는 것만으로 자동으로
재서 맞춰줍니다.

CHARGE 는 도중에 놓으면 LEAK 이 나지만, **다시 잡으면 그 지점부터 이어집니다.**

### 곡 선택

| 키 | 동작 |
|---|---|
| `W`/`S` | 곡 이동 |
| `A`/`D` | 난이도 이동 |
| `ENTER` | 플레이 |
| `F1` / `F2` | 에디터로 열기 / 새 채보 만들기 |
| `F4` | 연습 모드로 열기 (구간 반복 / 배속 / 판정 완화) |
| `F5` | songs 폴더 다시 스캔 |
| `F8` | 지금 곡을 시연 플레이로 보기 |
| `F9` | 온라인 곡 목록 (다운로드) |

아무 조작 없이 30초가 지나면 자동으로 **시연 플레이**가 시작됩니다.

### 전역

| 키 | 동작 |
|---|---|
| `F3` | 디버그 오버레이 (draw call / quad 수) |
| `F7` | 에셋 리로드 (스킨 이미지 / SFX / 폰트) |
| `F11` | 전체화면 |
| `F12` | 스크린샷 → `screenshots/` |

타이틀 화면 메뉴의 **PROFILE** 에서 누적 플레이타임 / 업적 / 티어를 볼 수 있습니다
(자세한 내용은 8장).

## 3. 곡 추가/제작

`songs/README.txt` 에 폴더 구조가 간단히 정리되어 있습니다 — 곡 폴더를 넣고
`F5`, 채보가 없으면 `F2` 로 인게임 에디터에서 새로 만들면 됩니다.

곡 선택 화면에서 `F1`(에디터로 열기)을 누르면 인게임 채보 에디터가 열립니다.
세로축이 시간(위 = 미래), 가로축이 레인인 2D 격자이고, 왼쪽에 파형이 그려져서
킥/스네어 위치를 눈으로 보고 찍을 수 있습니다.

| 조작 | 동작 |
|---|---|
| 좌클릭 | 노트 배치 (아래로 드래그하면 CHARGE) |
| `Shift`/`Alt` + 좌클릭 | bounce / spin 노트로 배치 |
| 우클릭 | 삭제 |
| 휠 / `Ctrl`+휠 | 스크롤 / 확대·축소 |
| `SPACE` | 재생 / 정지 |
| `[` `]` | 스냅 (1/1 ~ 1/32) |
| `,` `.` | 오프셋 -1 / +1 ms |
| `M` | 메트로놈 |
| `Ctrl+S` / `Ctrl+Z` / `Ctrl+Y` | 저장 / 실행 취소 / 다시 실행 |
| `F5` | 저장 후 지금 위치에서 바로 플레이 테스트 |

플레이 중에 채보 파일이 바뀌면 자동으로 다시 읽고 같은 위치에서 재시작합니다.

## 4. 에셋(스킨) 바꾸기

전부 **파일을 넣기만 하면 되고, 없으면 게임이 알아서 그립니다.** `F7` 로 즉시 반영.

| 위치 | 넣는 것 |
|---|---|
| `assets/skins/<이름>/` | `track` `note_pulse` `charge_pulse` `judge_line` `particle` (.png) |
| `assets/sfx/` | `hit` `miss` `ui_move` `ui_select` `metronome` `metronome_hi` (.wav/.ogg) |
| `assets/fonts/` | `.ttf` / `.otf` 하나 |

새 스킨은 `assets/skins/<이름>/` 폴더를 만들고 설정 화면의 "노트 스킨"에서 고르면 됩니다.

## 5. 편의성 / 성능 기능

- **로컬 멀티프로필** — 계정 없이 이 컴퓨터에서 여러 명이 이름을 나눠 씁니다. 타이틀 →
  PROFILE 에서 `R`(이름 변경) / `TAB`(전환·새로 만들기).
- **키 리바인드** — 설정 화면에서 레인 항목을 고르고 `ENTER`, 원하는 키를 누르면 바로 바뀝니다.
- **배속 방식** — MMOD(BPM 비례, 기본) / CMOD(BPM 과 무관한 고정 속도).
- **노트 배치 모드** — OFF / MIRROR(좌우 반전) / RANDOM(무작위 재배치).
- **저지연 오디오** — SFX/히트음은 저지연 엔진이 우선 처리하고, 장치 문제가 있으면
  자동으로 대체됩니다. WASAPI 배타모드는 설정에서 켤 수 있습니다.
- **프레임 상한 해제** — vsync 를 끄면 상한을 정하거나 완전 무제한으로 돌릴 수 있습니다.
  144/240/360Hz+ 모니터 전부 지원합니다.
- **안티에일리어싱** — OFF / FXAA(가벼움) / SSAA 2x 중 고릅니다.
- **설정 프리셋** — "성능/플레이 프리셋"에서 저사양/캐주얼/전문 중 골라 한 번에 적용합니다.
- **노트 기믹** — `bounce`(판정선 앞에서 쫀득하게 튕기고 판정도 후해짐), `spin`(치는 순간
  화면이 쫀득하게 한 바퀴 돎), `sudden`(구간 동안 노트가 판정선 가까이 와야 보임),
  `mine`(지뢰 — 누르면 안 되는 노트), `hidden`(판정선 가까이 와야 보이는 은신 노트).
- **스킨 희귀도** — COMMON → UNCOMMON → RARE → LEGENDARY 는 티어 해금 순서 그대로,
  **MYTHIC** 은 특정 채보를 클리어해야만 풀리는 스킨 전용 최상급 등급입니다
  (fire / space / storm — 각 폴더의 README.txt 참고).
- **최고 기록 표시** — 곡 선택 화면에서 난이도를 고르면 그 채보의 최고 점수/등급/클리어
  ·플레이 횟수가 정보 패널에 바로 보입니다(한 번도 안 쳐봤으면 "기록 없음").

## 6. 연습 모드

곡 선택에서 `F4`. 어려운 구간만 반복해서 익히는 용도입니다.

| 키 | 기능 |
|---|---|
| `[` `]` | 구간 시작/끝 지정 (둘 다 찍으면 자동 반복) |
| `L` | 반복 켜기/끄기 |
| `BACKSPACE` | 구간 해제 |
| `3` `4` | 배속 -/+ (0.5x ~ 1.5x) |
| `9` `0` | 판정 완화 -/+ (x1.0 ~ x3.0) |

배속이 1.0 이 아닌 동안은 **음악이 꺼지고 노트만 느려집니다.** 1.0 으로
되돌리면 그 위치에서 음악이 다시 붙습니다. 연습 기록은 프로필/업적/기록에
반영되지 않습니다.

## 7. 멀티플레이

타이틀 → **MULTIPLAYER**. **비동기 스코어 대결**입니다 — 각자 자기 화면에서 같은
채보를 플레이하고 점수만 비교하므로, 핑이 판정에 전혀 영향을 주지 않습니다.

| 모드 | 규칙 |
|---|---|
| **경쟁** | 최종 점수 순위. 1위가 승리 |
| **협력** | 전원 점수 합계가 목표 점수를 넘으면 클리어 |

**참가 방법**

- **공개 방** — 같은 네트워크(LAN)에 있으면 방 목록에 자동으로 뜹니다. 고르고 ENTER.
- **비공개 방** — 목록에 안 뜹니다. 호스트가 알려준 `IP:포트` 를 직접 입력해 접속합니다.

**곡이 없어도 됩니다** — 방에 들어가면 호스트가 채보와 음원을 직접 보내 주고
그대로 플레이합니다.

인터넷 너머로 하려면 호스트가 **27180/TCP 포트포워딩**을 해야 합니다.

경쟁에서 1위를 하거나 협력 목표를 달성하면 **멀티플레이 전용 업적**이 열립니다.

## 8. 진행 상황 — 프로필 / 업적 / 티어

플레이타임과 업적으로 포인트를 모아 티어가 오릅니다.

```
F - E - D - C - B - A - S - SS - X - XX - RED - RED_MAX
```

- **포인트** = 해금한 업적의 포인트 합 + 누적 플레이타임(분당 2pt)
- 오토플레이 중에는 플레이타임도, 업적/기록도 쌓이지 않습니다 (티어 자동 파밍 방지)
- 티어가 오르면 새 **노트 스킨**과, 히트할 때 더 화려해지는 **VFX**가 풀립니다.

곡 하나를 처음으로 **FULL CHAIN**(끊김 없이 완주) 하면 곡 선택 화면에 **금색 테두리**가,
처음으로 **PERFECT SYNC**(전부 SYNC) 하면 **무지개 테두리**가 붙습니다 — 이후 계속 표시됩니다.

타이틀 화면 **PROFILE** 메뉴에서 지금 티어·다음 티어까지 남은 포인트·누적 통계
(플레이타임/플레이 횟수/FULL CHAIN·PERFECT 횟수/최고 체인)와 전체 업적 목록
(달성/미달성)을 볼 수 있습니다.

진행 상황은 설정과 분리된 `profile.json` 에 저장됩니다. 초기화하고 싶으면
게임을 끈 상태에서 이 파일을 지우면 됩니다.
