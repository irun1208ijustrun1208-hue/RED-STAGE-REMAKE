# RED REMAKE

회로 기판 위를 흐르는 전류처럼 노트가 날아오는 **회로 하이웨이** 리듬 게임입니다.
메인 4레인 + 양쪽 사이드 레인 2개, 휘고·기울고·갈라지는 3D 트랙을 따라 판정선에 맞춰 누르세요.

**1.0.0 부터 C# 자체 엔진으로 완전히 새로 만들었습니다.**
DirectX 11 / DirectX 12 / Vulkan 중에서 고를 수 있습니다.

## 설치

1. [Releases](../../releases/latest) 에서 `RedRemake-<버전>-win-x64.zip` 을 받습니다.
2. 아무 폴더에 통째로 압축을 풉니다.
3. `RedRemake.exe` 를 실행합니다(.NET 설치 필요 없음).

처음에는 튜토리얼, 기초 연습 1~3, 데모 곡이 들어 있습니다. 타이틀에서 `F9`(ONLINE SONGS)를 누르면 이 저장소의 `songs/` 에 있는 곡을 바로 받을 수 있습니다.

**예전 파이썬 판(0.8)을 쓰던 분**

- 타이틀에서 `U` 로 업데이트하면 그대로 C# 판이 설치됩니다.
- 새 zip 을 같은 폴더에 덮어써도 됩니다.
- 기록(프로필·업적·티어)은 처음 실행할 때 자동으로 가져옵니다.
- 예전 채보로 받아둔 곡이 있으면 다시 받을지 물어봅니다.

이후 업데이트는 타이틀에서 `U` 를 누르면 됩니다. 업데이트 후 처음 켤 때 패치노트가 뜹니다.

## 조작

| 키 | 동작 |
|---|---|
| `D` `F` `J` `K` | 메인 레인 1~4 |
| `C` / `M` (또는 왼쪽·오른쪽 `Shift`) | 사이드 레인 왼쪽 / 오른쪽 |
| `Esc` | 일시정지 / 뒤로 |
| `F1` (타이틀) | 백과(조작·노트·기믹·곡·업적 설명) |
| `Shift`+`Tab` (타이틀) | UI 스킨 바꾸기 — CIRCUIT / STEAMPUNK |
| `F4` / `E` (곡 선택) | 연습 모드 / 채보 에디터 |
| `F3` | 공식 대회 창 |
| `/` `Tab` `F` `R` (곡 선택) | 검색 / 정렬 / 즐겨찾기 / 랜덤 |
| `O` `I` `?` (곡 선택) | 옵션 창(속도·미러·게이지·연습) / 기록 창 / 모든 단축키 |
| `Ctrl`+`R` (플레이 중) | 처음부터 다시 |

키는 설정에서 바꿀 수 있습니다.

## 판정

| 판정 | 뜻 |
|---|---|
| **PRIME** | 완벽(±18ms), 점수 100% |
| **SYNC** | 정확(±42ms), 점수 97% |
| **DRIFT** | 살짝 어긋남(±80ms), 점수 60%, FAST/SLOW 표시 |
| **FADE** | 많이 어긋남(±120ms), 점수 30%, 체인은 이어지고 전류는 조금만 오름 |
| **BREAK** | 놓침 — 체인이 끊어짐 |

점수는 0~10,000,000 입니다. **CURRENT**(전류 게이지)가 끝났을 때 70% 이상이면 클리어입니다.
게이지는 곡 선택 `O` 에서 EASY / NORMAL / HARD 로 고를 수 있고, 결과는 클리어 램프(ASSIST · EASY · CLEAR · HARD · FULL CHAIN · PERFECT)로 남습니다.

## 노트 기믹

- **지뢰**: 누르면 BREAK
- **은신**: 가까이 와서야 나타남
- **서지**: 판정선 앞에서 가속
- **페이즈**: 박자에 맞춰 깜빡임
- **고스트**: 옆 레인에 가짜 잔상
- **버스트**: 여러 번 연타
- **시프트**: 다른 레인에서 미끄러져 들어옴
- **스핀**: 화면이 출렁임
- **스네이크 홀드**: 누른 채로 레인을 옮겨 감(꺾이는 자리에서 새 레인 키로 바꿔 짚기)
- **분열**: 하나로 내려오다 판정선 앞에서 2~3개로 갈라짐
- **바운스**: 치면 튕겨 올랐다가 다른 레인에 떨어져 한 번 더
- **맥박 홀드**: 홀드 중 눈금마다 뗐다 누르면 보너스(놓쳐도 판정 영향 없음)
- **사이드 조합**: 사이드 키를 누른 채로 쳐야 하는 노트
- **레인 봉쇄**: 그 구간 동안 레인에 셔터가 내려옴(눌러도 감점 없음)
- **노트별 속도**: 노트마다 0.25~4배로 다르게 내려옴

새 기믹은 기본 곡 `기믹 체험` 에서 하나씩 연습할 수 있습니다.

## 멀티플레이

타이틀 → **MULTIPLAYER**.

1. 방장이 방을 만듭니다. 같은 네트워크에서는 방 목록에 자동으로 뜹니다. 방장이 `G` 로 개인전 / 팀전 / **협동**(팀 게이지 하나를 같이 지키고 점수 합계로 팀 목표 넘기기)을 고릅니다.
2. 모두 곡에 투표하고, 방장이 곡을 확정합니다. 곡이 없는 사람에게는 자동으로 전송됩니다.
3. 난이도는 각자 고르고 함께 시작합니다. 점수 기준이 같아서 난이도가 달라도 순위는 공정합니다.
4. 플레이 중 실시간 순위가 보이고, 끝나면 최종 순위가 나옵니다. 같은 방에서 바로 다음 곡으로 넘어갑니다.

곡 룰렛, 핸디캡(판정 좁히기 / 배점 낮추기, 사람마다 0~3단계), 채팅, 실시간 관전(←/→ 로 선수 바꾸기), 강퇴, 핑 표시, 자동 재접속을 지원합니다. 중계 서버 없이 방장 PC 로 바로 연결됩니다.
공유기가 UPnP / NAT-PMP 를 지원하면 포트가 자동으로 열리고, 안 되면 방장이 공유기에서 **TCP 27180** 포트를 열어야 합니다.

## 공식 대회

개발자가 여는 공식 대회는 게임 화면 오른쪽 위에 알림으로 뜹니다. 알림을 누르거나 `F3` → 대회 내용·시간 → **참가하기**.
1:1 토너먼트, 서바이벌(탈락전), 스코어 어택, 기간제 랭킹전이 있고, 보상(코인·대회 칭호)은 결과가 확정되면 자동으로 받습니다.

## 모드

타이틀 → **MODES**: 아케이드(3곡을 골라 치고 평균 S 이상이면 EXTRA STAGE 보스 곡), 코스, 패턴 훈련장(계단·트릴·연타·동시치기·홀드 패턴을 정확도에 따라 BPM 이 오르내리며 반복).

## 리플레이 · 미션 · 통계

- 끝까지 친 판은 자동으로 리플레이가 저장됩니다(결과 화면 `V`, 프로필 `P`).
- 매일 오늘의 미션 3개와 연속 출석 보상이 있습니다.
- 프로필 `S` = 통계(점수 추이·판정 비율·평균 타이밍), 통계에서 `C` = 레벨별 클리어 표. 설정의 **오프셋 맞추기 마법사**로 싱크를 맞출 수 있습니다.
- 좋은 기록들로 계산한 **실력 레이팅**에 따라 1~24단계 등급이 정해지고, 내 최고 기록 리플레이가 **고스트**로 옆에서 같이 달립니다.

## 채보 에디터

곡 선택에서 `E`(새 채보는 `Ctrl`+`N`). **음원 파일(mp3·ogg·wav·flac·opus)을 게임 창에 끌어다 놓으면 새 곡**을 만들어 바로 엽니다.

- 오른쪽에 실제 게임 화면 미리보기(내 스킨·배속·기믹·트랙 변형 그대로)
- 재생 속도 25~100%(음정은 그대로), 구간 반복, 메트로놈, 탭으로 BPM 재기
- 키 입력 모드(`R`): 레인 키로 찍고, 재생 중이면 실시간 녹음
- 소리 나는 자리 표시와 자석, 패턴 채우기(계단·트릴·연타·점프·무작위), 좌우 반전 등 변형
- 채보 검사(겹침·손으로 못 치는 연타·음원 밖 노트·빈 구간·예상 레벨)
- 난이도 복제와 목표 레벨까지 솎기, 다른 난이도 겹쳐 보기, 30초마다 자동 저장
- 에디터 안에서 `F1` = 단축키와 마우스 사용법 전체

## 자동 채보기

zip 에 같이 들어 있는 `AutoChart.exe` 는 **음원 + MIDI** 로 채보를 만듭니다. MIDI 로 노트를 찍고, 음원으로 싱크를 맞춥니다. 왼쪽 단계(파일 → 싱크 → 트랙 → 난이도 → 미리보기·저장)를 따라가면 되고, 여러 곡을 한 번에 처리할 수도 있습니다. 자세한 사용법은 zip 안의 `AutoChart-Guide.md` 와 게임 백과(`F1`)의 "자동 채보기" 항목을 보세요.
